# Smart Sri Lankan Healthcare Frontend Portal (React 18 + Vite)

Frontend web application for the Smart Sri Lankan Healthcare Management & Analytics Platform.

## Portals & Pages
- **Public & Auth**: Landing page, Specialist Doctor directory, Departments directory, International Patients, Login, Register, Forgot Password.
- **Patient Portal**: Dashboard, Book Appointment, My Appointments, Medical Records, Lab Reports, Prescriptions, Payments, Notifications, Feedback.
- **Doctor Portal**: Dashboard, Today's OPD Appointments, Patient EMR Dossier, Prescriptions, Lab Requests, Clinical Analytics.
- **Admin Portal**: Operations Dashboard, User Management, Pharmacy Inventory, Diagnostic Lab Management, Billing & Financial Reports.

## Running Locally

```bash
npm install
npm run dev
```

The frontend will run at `http://localhost:5173`.
